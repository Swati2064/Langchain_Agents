## 📌 About the Project

This project demonstrates **AI-powered Data Analysis** using **LangChain, Google Gemini, and Pandas**.

The AI agent can understand natural-language questions and analyze a Pandas DataFrame.

---

## 🚀 Features

* 🤖 LangChain AI Agents
* 🧠 Google Gemini LLM
* 🐼 Pandas DataFrame Analysis
* 📊 Titanic Dataset Analysis
* 🔍 Natural-language data queries
* 🧹 Missing-value analysis
* 📈 DataFrame comparison
* 🔐 Secure API key management

## ⚙️ Installation

```bash
git clone https://github.com/Swati2064/langchain-gemini-dataframe-agent.git
cd langchain-gemini-dataframe-agent
pip install langchain langchain-experimental langchain-google-genai pandas python-dotenv jupyter
```

---

## 🔐 API Key

Create a `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Never upload your `.env` file or API keys to GitHub.
